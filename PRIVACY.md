# Seg34-C11 隐私说明 / Privacy Policy

## 中文

Seg34-C11 表盘不收集个人数据，也不向任何外部服务器上传个人数据。表盘仅在手表本地调用 Garmin Connect IQ 系统提供的四项权限，以显示所选信息。

| 权限 | 本地用途 |
| --- | --- |
| `ComplicationSubscriber` | 读取 Garmin 系统提供的表盘数据项 |
| `Positioning` | 读取可用的位置信息供表盘本地计算 |
| `SensorHistory` | 读取手表保存的传感器历史，用于显示历史数据和图表 |
| `UserProfile` | 读取手表上的用户资料，用于显示相关指标 |

Garmin 天气使用 Garmin 系统提供的数据。GitHub Issues 是公开反馈渠道，请勿在文字或截图中附带个人资料、位置或健康数据。

## English

The Seg34-C11 watch face does not collect personal data or upload it to any external server. It uses only the following four Garmin Connect IQ permissions locally on the watch to display selected information.

| Permission | On-device use |
| --- | --- |
| `ComplicationSubscriber` | Reads watch face data supplied by the Garmin system |
| `Positioning` | Reads available location information for on-device calculations |
| `SensorHistory` | Reads sensor history stored on the watch for historical values and charts |
| `UserProfile` | Reads the profile stored on the watch to display related metrics |

Weather data comes from Garmin Weather. GitHub Issues are public. Leave personal, location, and health information out of your feedback and screenshots.
